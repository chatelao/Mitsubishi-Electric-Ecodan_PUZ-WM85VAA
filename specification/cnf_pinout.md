# Dual Fan Connector Pinout Specifications (`CNF1` & `CNF2`)

## 1. Overview

The Mitsubishi Electric Ecodan PUZ-WM85VAA outdoor unit utilizes a twin-fan chassis equipped with two identical 6-pin BLDC (Brushless Direct Current) fan motor interface connectors on the main inverter PCB:

- **`CNF1`**: Upper Fan Motor Connector
- **`CNF2`**: Lower Fan Motor Connector

Both connectors route high-voltage DC power alongside low-voltage DC logic and analog/digital speed control and feedback signals to the integrated BLDC motor driver circuitry located inside each fan motor assembly.

---

## 3. Signal Waveforms and Dynamic Response

### 3.1 Speed Command Voltage ($V_{\text{sp}}$)

- **Signal Characteristics**: Direct DC voltage level.
- **Dynamic Speed Law**:
  $$N_{\text{actual}} = \begin{cases} 0 & \text{if } V_{\text{sp}} < 1.0\text{V} \\ 240 \times V_{\text{sp}} - 60 & \text{if } 1.5\text{V} \le V_{\text{sp}} \le 6.5\text{V} \end{cases}$$
- **Impedance**: High input impedance at fan motor ($>100\text{ k}\Omega$). Main board drives $V_{\text{sp}}$ via active OpAmp / RC low-pass filtered PWM output.

### 3.2 Feedback Tachometer Pulse ($FG$)

- **Signal Characteristics**: Square wave pulse train with frequency proportional to motor rotational speed:
  $$f_{\text{FG}} = \frac{N_{\text{actual}} \times P}{60} = \frac{N_{\text{actual}} \times 4}{60} = \frac{N_{\text{actual}}}{15} \text{ Hz}$$
- **Representative Frequencies**:
  - $300\text{ RPM} \implies 20.0\text{ Hz}$
  - $780\text{ RPM} \implies 52.0\text{ Hz}$ (Target Acoustic Ceiling)
  - $1150\text{ RPM} \implies 76.7\text{ Hz}$ (Standard Heating Max)
  - $1500\text{ RPM} \implies 100.0\text{ Hz}$ (Absolute Rated Max)

## 4. Hardware Interceptor Interface Considerations

When inserting the Stage 1 Dual-Channel Interceptor module between `CNF1`/`CNF2` on the main PCB and the fan motor harness:

1. **`Vcc_HV` (Pin 1)**: Must pass through directly with high-voltage isolation ($>600\text{V}$ clearance rating).
2. **`Vcc_Logic` (Pin 4)**: Powers the interceptor module's local 5V LDO voltage regulator.
3. **`Vsp` (Pin 5)**: Intercepted via $0.6875\times$ resistor divider ($10\text{ k}\Omega / 22\text{ k}\Omega$) with $5.1\text{V}$ Zener clamp into the ATtiny1616 ADC, and re-generated via DAC + OpAmp ($G=1.5$) powered from Pin 4 ($15\text{V}$).
4. **`FG` (Pin 6)**: Intercepted from motor tachometer output, conditioned via Schmitt trigger into ATtiny1616 timer capture, and synthesized back to main PCB via open-drain MOSFET ($f_{\text{synth}} = f_{\text{actual}} / k$).
